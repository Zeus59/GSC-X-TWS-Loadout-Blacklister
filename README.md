# GSC X TWS Loadout Blacklister

Companion tool for the **TWS X GSC Loadout Editor** mod (Arma Reforger).
It builds the blacklist for the server: every item prefab from your installed mods that is **not** listed in any arsenal catalog.

## Requirements

- Windows, [Python 3](https://www.python.org/downloads/) (tick "py launcher" during install)
- `customtkinter` — installed automatically by `Start.bat` on first run

## Usage

1. Double-click `Start.bat`.
2. Set the **Addons folder** (default: `Documents\My Games\ArmaReforger\addons`).
3. In the mod list tick:
   - **Arsenal lists** (blue): read this mod's `Configs/EntityCatalog` as the allowed list. Mods with "arsenal" in the name are pre-selected.
   - **Allow whole mod** (green): never block any item of this mod.
4. Optional: add regexes under **Never block** (matched against the prefab path, one per line).
5. Click **Generate list** (takes about a minute).
6. Copy the output file to the server as `<profile>/LoadoutEditor/native_blocked_auto.txt` and restart the server.

Your settings are saved next to the script in `Blacklister.json`.

## How it works

1. Reads every mod in the addons folder (`data.pak` = file index + prefabs, `resourceDatabase.rdb` = path → GUID).
2. Collects every prefab referenced by the selected arsenal mods' `Configs/EntityCatalog/**.conf` (including `.conf` files in other mods that a catalog references) = allowed GUIDs.
3. A prefab counts as an item if it or a parent prefab has an `InventoryItemComponent`. Vehicles, buildings and characters are never blocked.
4. Items whose GUID is not allowed are written as `{GUID}Path # Mod`.

Mods are only read, never changed.

## Output format

```
# Generated by the GSC X TWS Loadout Blacklister: items that are in no arsenal list.
{6A5AFAB3BA1AB2D1}Prefabs/Howitzer/Howitzer_2A36_Guided.et # SomeMod_6A5AF9F1AB9EC257
```
